# Vaibhav Nagar Portfolio

Personal website built with Jekyll using the [Mediator theme](https://github.com/dirkfabisch/mediator). GitHub Pages loads the theme from `remote_theme` in `_config.yml`.

## Local preview

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000` to preview the site.
